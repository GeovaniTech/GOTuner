# GOTuner 1.0.0 — release notes draft

## English

- Tune standard guitar strings with real-time microphone pitch detection.
- See frequency, target note and tuning deviation in cents.
- Follow clear tighten/loosen guidance and a smooth tuning indicator.
- Use a minimal dark interface in English or Portuguese.
- Microphone audio is processed locally; Android includes usage analytics and crash diagnostics as described in the privacy policy.

## Português

- Afine as cordas do violão na afinação padrão com detecção em tempo real pelo microfone.
- Veja frequência, nota de referência e desvio em cents.
- Receba orientações para apertar ou afrouxar a corda e acompanhe o indicador de afinação.
- Use a interface escura em português ou inglês.
- O áudio é processado no aparelho; a versão Android inclui análise de uso e diagnóstico de falhas conforme a política de privacidade.

This is a draft for the first Android release, not confirmation of publication. Do not claim real-device certification until the manual matrix passes.
